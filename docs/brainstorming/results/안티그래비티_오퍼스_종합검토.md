## 2. 합의 사항: 4개 문서가 모두 동의하는 것

4개 문서를 교차하면, **예외 없이 합의된 사항**이 7개 있다. 이것들은 논의 여지 없이 최종안에 포함되어야 한다.

### ✅ 합의 1. 원본 EDI의 뼈대를 유지한다

모든 문서가 "EDI를 버리고 새로 만드는 것이 아니라, EDI를 업그레이드한다"고 결론냈다. 구체적으로 아래 4개 요소는 전원 합의:

- **일단위 계산**
- **시간가중 유효강수량(EP)** 
- **dry-duration 기반 DS 자동 확장**
- **일강수량 단일 입력**

### ✅ 합의 2. 집중호우 유출보정(CEDI 계열)은 반드시 포함한다

4개 문서 모두 Kim et al.(2009)의 CEDI 아이디어(집중호우 초과분의 급속감쇠)를 핵심 개선축으로 채택했다.

### ✅ 합의 3. 고정 80mm 임계값은 전국 운영에 부적합하다

- 문서 A: "지역별 상위 5% 분위수 기반 동적 임계값"
- 문서 B: "max(80mm, 지점별 95백분위)"
- 문서 C: "지점별·월별 젖은날 강수의 상위 분위수"
- 문서 D: "T=80mm 기반이되 지역 보정 필요"

→ **전국 서비스용 임계값은 지점별(또는 격자별) 분위수 기반으로 적응형 설계**해야 한다는 데 합의.

### ✅ 합의 4. 표준화 방식을 개선해야 한다

4개 문서 모두 원본 EDI의 단순 평균/표준편차 기반 표준화(또는 감마분포 피팅)가 불안정하다고 진단했다. 해법은 조금씩 다르지만, 방향은 동일:

- **경험적 CDF(empirical quantile) 기반 비모수 표준화** → 정규분포 역변환

### ✅ 합의 5. SPI 다기간 병렬 제시를 대체할 "단일 대표지수"여야 한다

4개 문서 모두 "공식 서비스에는 지수 하나만 내보낸다"는 원칙에 합의.

### ✅ 합의 6. 공식 대표지수에 앙상블/다변수 하이브리드는 부적합하다

- 앙상블은 설명력 약화, 가뭄 정의 흐림, 책임 추적 어려움
- PET/토양수분/저수율은 영향정보이지 기상가뭄 대표지수에 넣을 요소가 아님

### ✅ 합의 7. 보조지표는 대표지수와 분리하여 제공한다

- **PRN** (해갈 필요 강수량): 4개 문서 모두 언급
- **지속일수**: 4개 문서 모두 언급
- **강수 평년비** 또는 **AWRI**: 3~4개 문서 언급
- 핵심: "headline은 하나, 설명은 부산물로 분리"

## 3. 쟁점 사항: 문서 간 견해가 갈리는 것

### 쟁점 1. EP 가중함수를 바꿀 것인가

| 문서 | 입장 | 근거 |
|:-----|:-----|:-----|
| A (E-EDI) | **바꾼다** → 지수감쇠 커널(τ 적응형) | 물리적 기반 강화, 계절·지역 맞춤 |
| B (ACE-EDI) | **바꾸지 않는다** → 원본 조화급수 유지 | 연속성 유지, 파라미터 부담 최소화, 서비스 설명 용이 |
| C (sc-CEDI-K) | **바꾸지 않는다** → 원본 구조 유지 | 운영 안정성 우선 |
| D (scCEDI) | **바꾸지 않는다** → 원본 구조 유지 | 핵심 철학 보존 |

> **판정**: 3:1로 **"원본 조화급수 EP 유지"** 가 우세. 적응형 커널은 이론적으로 매력적이나, (1) 파라미터(τ) 추정 부담이 크고, (2) 원본 EDI와의 연속성이 끊어지며, (3) 서비스 설명이 복잡해진다는 3가지 실무적 우려가 더 큼. **최종안은 원본 EP 구조를 유지하되, 유출보정은 초과분에만 적용하는 방식을 채택한다.**

---

### 쟁점 2. 기후 비정상성 대응 방식

| 문서 | 입장 | 구체안 |
|:-----|:-----|:------|
| A (E-EDI) | **이동 기후학** (지수가중 이동평균, 반감기 10년) | P2 우선순위로 후순위 배치 |
| B (ACE-EDI) | **언급 없음** | 표준화 개선으로 충분하다는 입장 |
| C (sc-CEDI-K) | **rolling 30년 자기보정** | scEDI(2022) 방식 채택 |
| D (scCEDI) | **rolling 30년 경험적 CDF** | scEDI 방식 채택 |

> **판정**: "이동 기후학"(문서A)과 "rolling 30년 자기보정"(문서C·D)은 **같은 문제를 다른 언어로 풀려는 시도**다. 차이는:
> - 이동 기후학: 연도별 가중치를 연속적(지수가중)으로 적용 → 더 세밀하지만 반감기 선택 임의성
> - rolling 30년: 직전 30년을 균등하게 사용 → 더 단순하고 WMO 평년값과 개념적 일관성
> 
> **최종안**: Phase 1에서는 **rolling 30년** 방식으로 시작(단순, 설명 용이, scEDI 검증 이력 있음). Phase 2에서 지수가중 이동평균과 비교 민감도 분석 수행 후 결정.

---

### 쟁점 3. AWRI(절대 물부족 보조지수)의 위상

| 문서 | 입장 |
|:-----|:-----|
| A (E-EDI) | **핵심 부산물로 자동 산출**, 대국민 서비스에 상시 표출 |
| B (ACE-EDI) | **"AWRI 성격의 보조값"** 으로 언급, 공식 대표에는 미포함 |
| C (sc-CEDI-K) | 직접 언급 없음, 강수 평년비로 대체 |
| D (scCEDI) | 직접 언급 없음 |

> **판정**: AWRI 자체는 이론적으로 유용하나, 현 단계에서 공식 서비스에 추가하면 "지수가 두 개"가 되어 대표지수 단일화 원칙과 충돌할 수 있다. **최종안**: Phase 1에서는 AWRI를 **내부 진단용**으로만 산출. 대국민 서비스에서는 **"최근 90일 강수 평년비"** 가 절대 물부족을 간접적으로 설명하는 역할을 대체한다. Phase 2~3에서 AWRI의 대국민 표출 여부를 별도 검토.

---

### 쟁점 4. 합의도 점수의 포함 여부

| 문서 | 입장 |
|:-----|:-----|
| A (E-EDI) | **핵심 부산물로 자동 산출** (다중 시간척도 부호 일치도) |
| B (ACE-EDI) | 언급 없음 |
| C (sc-CEDI-K) | SPI 3/6은 **내부 합의도 점검용으로만 병행** |
| D (scCEDI) | 언급 없음 |

> **판정**: 합의도 개념은 매력적이나, 대국민 서비스에 포함하면 "지수 외에 또 하나의 판단 축"이 추가되어 오히려 혼선을 줄 수 있다. **최종안**: 합의도는 **내부 품질관리(QC)용으로만 운영**한다. 대국민 서비스 화면에는 표출하지 않는다.

---

### 쟁점 5. 등급 체계

| 문서 | 등급 구간 |
|:-----|:---------|
| A (E-EDI) | 정상(≥0) / 관심(-0.5~0) / 약한(-1.0~-0.5) / 보통(-1.5~-1.0) / 심한(-2.0~-1.5) / 극심(<-2.0) → **6단계** |
| B (ACE-EDI) | 정상(≥-0.5) / 관심(-1.0~-0.5) / 약한(-1.5~-1.0) / 보통(-2.0~-1.5) / 심한(<-2.0) → **5단계** |
| C (sc-CEDI-K) | 정상(>-0.7) / 관심(-1.4~-0.7) / 주의(-2.0~-1.4) / 경계(-2.6~-2.0) / 심각(<-2.6) → **5단계** |
| D (scCEDI) | 관심(-1.0~-0.5) / 보통(-1.5~-1.0) / 심한(-2.0~-1.5) / 극한(<-2.0) → **4+단계** |

> **판정**: 등급 체계는 **후향 검증 후 확정**해야 한다. 연구 단계에서 미리 고정하면 파라미터 역전(등급이 결과를 왜곡)의 위험이 있다. **최종안**: Phase 1에서는 연속값(scCEDI-K 수치)으로만 운영하고, Phase 2 후향검증에서 과거 영향기록과의 일치도를 기준으로 등급 경계값을 확정한다.

## 4. 최종 확정 방향

### 4.1. 공식 명칭

모든 제안서의 핵심요소를 종합하면, 최종안의 구성은 다음과 같다:

> **원본 EDI의 뼈대** + **CEDI의 유출보정** + **경험적 CDF 자기보정 표준화**

이를 가장 정확하게 지칭하는 이름으로 **scCEDI-K** (self-calibrating Corrected EDI for Korea)를 채택한다.

- `sc`: self-calibrating (경험적 CDF 기반 비모수 표준화, rolling 30년)
- `C`: Corrected (집중호우 유출보정)
- `EDI`: 원본 EDI 골격 유지
- `K`: for Korea (한국형 전국 적응)

### 4.2. 확정된 알고리즘 골격 (5 STEP)

```
STEP 1. 입력
  └─ 일강수량 P(t), 최소 30년 이상

STEP 2. 집중호우 유출보정
  └─ 임계값: max(80mm, 지점별 우일(wet-day) 강수 95백분위)
  └─ P_base(t)   = min(P(t), Threshold)
  └─ P_excess(t) = max(P(t) - Threshold, 0)
  └─ 초과분은 원본 EP 가중치 대신 τ_fast(3~5일) 급속감쇠 적용

STEP 3. 보정 유효강수량(CEP) 계산
  └─ 원본 EDI 식(2) 조화가중 구조 그대로 유지
  └─ 입력만 P(t) → P_base(t)로 교체, 초과분은 별도 감쇠
  └─ DS 자동 확장: DS(t) = 365 + dry_duration(t) - 1

STEP 4. 자기보정 비모수 표준화
  └─ 기후학: 해당 시점 직전 rolling 30년의 달력일별 CEP 기준
  └─ 편차: DCEP(t) = CEP(t) - rolling_mean_CEP(doy)
  └─ 표준화: 달력일 ±15일 창 풀링 → 경험적 CDF → 정규역변환
     scCEDI-K(t) = Φ⁻¹(F_emp(DCEP(t)))

STEP 5. 서비스 출력
  └─ 대표지수: scCEDI-K 단일값
  └─ 보조설명 (분리 패널):
     ① PRN: 정상 회복에 필요한 1일 강수량
     ② 지속일수: scCEDI-K < 0 연속 일수
     ③ 최근 90일 강수 평년비
  └─ 등급: Phase 2 후향검증 후 확정
```

### 4.3. 확정된 제외 목록

아래는 최종안에서 **의도적으로 제외**한 요소와 그 근거이다.

| 제외 요소 | 근거 |
|:---------|:-----|
| EP 가중함수 전면 교체 (적응형 커널) | 3:1 합의로 기각. 파라미터 부담, 연속성 단절, 설명 복잡성 |
| PET/증발산/토양수분 입력 | 기상가뭄 정의 흐림. 영향정보로만 분리 운영 |
| SPI/SPEI 앙상블 대표지수 | 설명력 약화, 기간선택 문제 미해결, 책임추적 곤란 |
| 저수율/댐 저수량 직접 반영 | 적응의 영역이지 기상가뭄 자체가 아님 |
| AWRI 대국민 표출 (Phase 1) | 지수 이원화 우려. 내부진단용으로만 산출 |
| 합의도 대국민 표출 | 판단축 추가로 오히려 혼선. 내부 QC용으로만 운영 |
| 등급 사전 고정 | 후향검증 전 고정 시 파라미터 역전 위험 |

### 4.4. 유보 사항 (Phase 2에서 검토)

| 유보 요소 | Phase 2 검토 내용 |
|:---------|:----------------|
| 이동 기후학 vs rolling 30년 | 지수가중 이동평균(반감기 10~15년)과 rolling 30년 비교. 비정상성 대응 효과 정량화 |
| AWRI 대국민 표출 여부 | 절대 물부족 설명력 vs 지수 이원화 혼선 비교. 시범 서비스 사용자 반응 확인 |
| 합의도 표출 여부 | 내부 QC에서 유용성 검증 후, 전문가 패널 표출 여부 결정 |
| 등급 경계값 확정 | 과거 영향기록(가뭄선언, 제한급수, 언론 보도)과의 적중률 기반 확정 |
| GPD 꼬리 외삽 | 극단 가뭄 빈도 추정에 경험적 CDF만으로 충분한지 검증 |

## 5. 4개 문서의 아이디어 흡수 현황

각 문서가 제안한 핵심 아이디어가 최종안에 어떻게 반영되었는지 정리한다.

| 문서 | 핵심 아이디어 | 최종안 반영 |
|:-----|:-----------|:----------|
| **A (E-EDI)** | 적응형 커널 EP | ❌ 제외 (연속성·단순성 우선) |
| | 유출보정 (동적 Pthreshold) | ✅ 흡수 → max(80mm, 95pctl) |
| | 비매개변수 표준화 (±15일 풀링) | ✅ 흡수 → STEP 4 핵심 |
| | 이동 기후학 (반감기 10년) | ⏳ 유보 → Phase 2 비교 |
| | AWRI 자동 산출 | ⏳ 유보 → Phase 2 검토 |
| | 합의도 점수 자동 산출 | ⏳ 유보 → 내부 QC용 |
| | P0/P1/P2 우선순위 체계 | ✅ 흡수 → 로드맵 기반 |
| **B (ACE-EDI)** | "원본 EP 유지 + 초과분만 보정" 최소주의 | ✅ 흡수 → 핵심 설계 원칙 |
| | 과도한 자유도 경고 | ✅ 흡수 → 적응형 커널 기각 근거 |
| | max(80mm, 95pctl) 임계값 | ✅ 흡수 → STEP 2 |
| | "공식 대표지수에서 빼야 할 것" 명시 | ✅ 흡수 → 제외 목록 |
| **C (sc-CEDI-K)** | scEDI(2022) rolling 30년 자기보정 | ✅ 흡수 → STEP 4 핵심 |
| | 지수명 sc-CEDI-K | ✅ 채택 |
| | scEDI 논문의 -1.4/-2.0 앵커값 | ⏳ 유보 → 등급 확정 시 참고 |
| | 문헌 기반 사실 vs 설계 추론 구분 | ✅ 흡수 → 문서 구조 |
| **D (scCEDI)** | "scCEDI" 3요소 결합 제안 | ✅ 핵심 합치 → 최종안 골격 |
| | eRDI/SPEI 비교 분석 후 기각 | ✅ 흡수 → 제외 근거 |
| | alpha 계수 방식 유출보정 | ⏳ 대안 → τ_fast 방식과 비교 필요 |
| | 영향기록 기반 검증 강조 | ✅ 흡수 → 후향검증 핵심 |

## 6. 후향 검증 계획

### 6.1. 필수 비교 대상

| # | 지수 | 역할 |
|:-:|:-----|:-----|
| 1 | 원본 EDI | 기준선 (baseline) |
| 2 | CEDI (고정 80mm) | 유출보정 효과 분리 측정 |
| 3 | scEDI | 자기보정 효과 분리 측정 |
| 4 | **scCEDI-K** | 최종 제안안 |
| 5 | SPI-3 / SPI-6 | 현행 서비스 기준 비교 |

### 6.2. 검증 사례

| 사례 | 핵심 검증 질문 |
|:-----|:-------------|
| 1899~1903 서울 메가가뭄 | 장기 누적을 원본 EDI만큼 잘 추적하는가 |
| 1965 봄 단기 가뭄 | 단기 강수 부족을 놓치지 않는가 |
| 2006 집중호우 후 가을 건조 | 유출보정으로 가을 가뭄을 더 현실적으로 잡는가 |
| 2014~2015 중부 광역 가뭄 | 지역별 분포가 실제 피해와 부합하는가 |
| 2022~2023 전국 건조 | 최근 사례에서 운영 가능한가 |
| 집중호우 직후 재건조 전환 | flip-flop 없이 안정적 전환을 보이는가 |

### 6.3. 평가 지표

1. **가뭄 시작일/해갈일 탐지 오차** (일 단위)
2. **과거 영향기록(가뭄선언·제한급수·언론보도)과의 적중률**
3. **집중호우 후 과습 잔상 지속일수** (원본 EDI 대비 감소 여부)
4. **전국 지점 간 동일 등급의 영향 일관성**
5. **일별 등급 flip-flop 빈도** (서비스 안정성)

### 6.4. 민감도 분석 항목

| 파라미터 | 시험 범위 | 목적 |
|:---------|:---------|:-----|
| 유출보정 임계값 | 50 / 80 / 110 mm, 90pctl / 95pctl / 99pctl | 최적 Pthreshold 확정 |
| τ_fast | 2 / 3 / 5 / 7 / 10일 | 초과분 감쇠 속도 확정 |
| 풀링 창 크기 | ±7 / ±15 / ±30일 | 표준화 안정성 vs 시간 해상도 |
| rolling 기후학 기간 | 20 / 30 / 40년 | 비정상성 대응과 안정성의 균형 |
| alpha vs τ_fast 방식 | 고정계수 vs 감쇠함수 | 유출보정 구현 방식 확정 |

## 7. 구현 로드맵 (확정)

```
Phase 1 (3개월): 코어 개발 + 초기 검증
├─ 원본 EDI 재현 코드 (검증 기준선 확보)
├─ 유출보정 모듈 (STEP 2)
├─ rolling 30년 + 경험적 CDF 표준화 모듈 (STEP 4)
├─ 민감도 분석 (Pthreshold, τ_fast, 풀링 창)
└─ 서울 장기자료 6개 사례 후향검증

Phase 2 (3개월): 전국화 + 심화 검증
├─ 전국 160개 지점 일괄 적용
├─ SPI 3/6, 원본 EDI, CEDI, scEDI와 체계적 비교
├─ 등급 경계값 확정 (영향기록 기반)
├─ 이동 기후학 vs rolling 30년 비교 분석
├─ AWRI/합의도 대국민 표출 여부 검토
└─ alpha 방식 vs τ_fast 방식 최종 확정

Phase 3 (3개월): 시범 운영
├─ 대국민 서비스 화면 프로토타입
├─ 내부 브리핑용 문안 표준화
├─ 현행 SPI 6과 병행 운영
├─ 피드백 수집 및 임계값 미세 보정
└─ 학술 논문 초안 작성

Phase 4 (이후): 공식 전환
├─ 공식 대표지수를 scCEDI-K로 전환
├─ SPI 계열은 내부 QC용으로만 유지
├─ 연간 파라미터 리뷰 체계 수립
└─ 국제 학술 발표 및 공유
```

## 8. 최종 결론: 한 문단 요약

4개 브레인스토밍 결과물은 세부 명칭과 표현은 달랐으나, **핵심 구조에서 놀라울 정도로 수렴**했다. 모든 문서가 동의한 것은 (1) 원본 EDI의 뼈대(일단위, EP, DS 자동확장)는 유지하고, (2) 집중호우 유출보정을 추가하며, (3) 감마분포 대신 경험적 CDF 비모수 표준화를 적용하고, (4) 하나의 대표지수로 서비스한다는 것이다. 쟁점이 된 적응형 커널 EP는 실무적 부담이 크다는 다수 의견에 따라 제외하고, 기후 비정상성 대응은 Phase 1에서 rolling 30년으로 시작한 뒤 Phase 2에서 이동 기후학과 비교하는 것으로 정리했다. 이 모든 것을 종합한 최종 권고안은 **scCEDI-K(self-calibrating Corrected Effective Drought Index for Korea)**이며, 이것이 "SPI 방식이 아닌 단일 가뭄지수로 기상가뭄을 서비스한다"는 프로젝트 목표를 가장 균형 있게 달성하는 해법이다.
