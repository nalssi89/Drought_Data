# 원본 EDI (1999) vs scCEDI-K v2 (최종 채택) 비교표

> **목적**: 원본 알고리즘과 최종 채택 알고리즘의 차이를 한눈에 파악한다.  
> **작성일**: 2026-04-04

---

## 1. 전체 구조 비교 (한 눈에 보기)

```
┌─────────────────────────────────────────────────────────────────────┐
│              원본 EDI (1999)              │     scCEDI-K v2 (2026)   │
├──────────────────────────────────────────┼──────────────────────────┤
│                                          │                          │
│  일강수량 P(t)                            │  일강수량 P(t)            │
│      │                                   │      │                   │
│      ▼                                   │      ▼                   │
│  ─────────────                           │  ★ 유출보정 ★             │
│  (보정 없음)                              │  Pc(t) = 초과분 감쇠      │
│      │                                   │      │                   │
│      ▼                                   │      ▼                   │
│  EP 계산                                  │  CEP 계산                │
│  (조화급수 가중)                           │  (조화급수 가중 유지)      │
│      │                                   │      │                   │
│      ▼                                   │      ▼                   │
│  DEP = EP - MEP                          │  DCEP = CEP - ★rolling★  │
│  (고정 30년 평균)                          │  (직전 30년 이동평균)      │
│      │                                   │      │                   │
│      ▼                                   │      ▼                   │
│  EDI = DEP / σ(DEP)                      │  ★ 비모수 표준화 ★        │
│  (평균/표준편차 단순 표준화)                │  Φ⁻¹(F_emp(DCEP))        │
│      │                                   │      │                   │
│      ▼                                   │      ▼                   │
│  EDI 단일값                               │  scCEDI-K 단일값          │
│  + PRN                                   │  + PRN(역산보정)          │
│                                          │  + 지속일수               │
│                                          │  + 90일 평년비            │
└──────────────────────────────────────────┴──────────────────────────┘

      ★ = 원본 대비 변경/추가된 부분
```

## 2. 항목별 상세 비교

| 비교 항목 | 원본 EDI (Byun & Wilhite, 1999) | scCEDI-K v2 (최종 채택, 2026) | 변경 이유 |
|:---------|:-------------------------------|:------------------------------|:---------|
| **입력 자료** | 일강수량 P(t) | 일강수량 P(t) | ✅ **동일** — 강수 전용 원칙 유지 |
| **계산 단위** | 일별 | 일별 | ✅ **동일** — 해갈·급변 포착 |
| **EP 가중함수** | 조화급수 Σ(1/n) 고정 | 조화급수 Σ(1/n) **그대로 유지** | ✅ **동일** — 연속성·설명력 보존 |
| **DS 자동확장** | DS = 365 + dry_duration - 1 | DS = 365 + dry_duration - 1 | ✅ **동일** — SPI 기간선택 문제 해결의 핵심 |
| **DS=15 단기 프레임** | EP_15 별도 산출 | **의도적 폐기** | ⚡ DS 자동확장이 단기 건조를 이미 포착 |
| | | | |
| **집중호우 보정** | ❌ **없음** — 큰 비 전량 EP에 반영 | ✅ **유출보정 추가** | ⚡ 한국형 집중호우 후 과습 판정 해결 |
| ↳ 임계값 | — | max(80mm, 지점별 95백분위) | 전국 적응형 (고정 80mm 탈피) |
| ↳ 초과분 처리 | — | Phase 1에서 α방식·τ_fast 비교 후 확정 | 민감도 분석으로 최적 방식 결정 |
| | | | |
| **기후학 (MEP)** | **고정 30년** 평년값 | **Rolling 30년** 이동 기후학 | ⚡ 기후 비정상성 대응 |
| ↳ 평활화 | 5일 이동평균 | ±7일 이동평균 (유사) | — |
| | | | |
| **표준화 방식** | DEP / σ(DEP) | **비모수 경험적 CDF** | ⚡ 감마분포 피팅 불안정 해결 |
| ↳ 분포 가정 | 암묵적 정규 가정 | **분포 가정 없음** | 비대칭 강수 분포에 자동 적응 |
| ↳ 샘플 수 | 달력일당 30개 | **±15일 풀링 → ~930개** | 샘플 부족 문제 해결 |
| ↳ 최종 변환 | 직접 표준화 | Φ⁻¹(F_emp) 정규역변환 | 확률적 해석 가능 |
| | | | |
| **PRN** | DEP / Σ(1/n) | DEP / Σ(1/n) + **유출보정 역산** | ⚡ "실제 필요 강수량"으로 보정 |
| **AWRI** | ❌ 없음 (Kim 2009에서 제안) | 내부 진단용 산출 (Phase 2 표출 검토) | — |
| **등급 체계** | EDI < -1.0 = 가뭄 | **후향검증 후 확정** (사전 고정 금지) | ⚡ 영향기록 기반 보정 필요 |
| | | | |
| **보조지표** | PRN만 | PRN + 지속일수 + 90일 평년비 | ⚡ 대국민 설명력 강화 |
| **서비스 지표 수** | EDI 1개 | scCEDI-K 1개 (headline) | ✅ **동일 원칙** — 단일 대표지수 |

## 3. 수식 비교 (핵심 단계만)

### STEP 2: 강수 입력

```
[원본 EDI]
  그대로 사용:  input = P(t)

[scCEDI-K v2]
  유출보정 적용:
    Threshold = max(80mm, P95_wetday)
    P_base(t)   = min(P(t), Threshold)
    P_excess(t) = max(P(t) - Threshold, 0)
    Pc(t) = P_base(t) + f(P_excess(t))   ← α 또는 τ_fast 감쇠
```

### STEP 3: 유효강수량

```
[원본 EDI]
  EP(t) = Σ(n=1→DS) [ (Σ(m=1→n) P(t-m+1)) / n ]

[scCEDI-K v2]
  CEP(t) = Σ(n=1→DS) [ (Σ(m=1→n) Pc(t-m+1)) / n ]
  ↑ 가중구조 100% 동일, 입력만 P → Pc로 교체
```

### STEP 4: 편차 계산

```
[원본 EDI]
  MEP = 고정 30년 달력일 평균 EP
  DEP(t) = EP(t) - MEP(doy)

[scCEDI-K v2]
  MCEP(t) = 직전 rolling 30년 달력일 평균 CEP
  DCEP(t) = CEP(t) - MCEP(doy)
```

### STEP 5: 표준화

```
[원본 EDI]
  EDI(t) = DEP(t) / σ_DEP(doy)
  → 달력일별 표준편차로 나눔 (모수적)

[scCEDI-K v2]
  pool = 과거 모든 해의 [doy-15 ~ doy+15] 구간 DCEP 값
  F_emp = empirical CDF from pool (~930 samples)
  scCEDI-K(t) = Φ⁻¹(F_emp(DCEP(t)))
  → 경험적 분포에서 확률값을 구한 뒤 정규역변환 (비모수적)
```

## 4. "무엇이 바뀌고 무엇이 안 바뀌었나" 요약

### 🔵 바뀌지 않은 것 (원본 EDI의 DNA)

| 요소 | 의미 |
|:-----|:-----|
| 일강수량 단일 입력 | 기상가뭄의 정의를 강수 부족으로 명확히 유지 |
| 조화급수 EP 가중함수 | 최근 비에 더 큰 가중치 → 현재 물가용량 추정 |
| DS 자동확장 | 가뭄이 길수록 평가창이 넓어짐 → SPI 기간선택 문제 원천 해결 |
| 단일 대표지수 체계 | 하나의 값으로 장단기 가뭄을 동시 추적 |
| PRN 산출 | 해갈 필요 강수량이라는 직관적 설명 유지 |

### 🔴 바뀐 것 (한국형 운영 최적화)

| 변경 | 해결하는 문제 | 근거 |
|:-----|:-----------|:-----|
| 집중호우 유출보정 추가 | 여름 큰 비 후 가을 가뭄 과소평가 | Kim (2009) CEDI |
| Rolling 30년 기후학 | 기후변화로 고정 평년값 노후화 | Park (2022) scEDI |
| 비모수 경험적 CDF 표준화 | 감마분포 피팅 불안정 (샘플 30개) | 회의록 핵심 문제 직접 해결 |
| 지점별 동적 임계값 | 전국 운영 시 서울 중심 80mm 편향 | 전국 160개 지점 강수 특성 차이 |
| PRN 역산 보정 | 유출보정 후 PRN이 실제 필요량과 괴리 | 3회 검증에서 신규 발굴 |
| DS=15 단기 프레임 폐기 | DS 자동확장이 이미 단기 포착 | 중복 제거 |

## 5. 대국민 서비스 출력 비교

### 원본 EDI 시절

```
┌─────────────────────────────────┐
│  서울  EDI = -1.23              │
│  PRN = 42 mm/day               │
└─────────────────────────────────┘
→ 숫자 두 개. "마이너스 1.23"이 무엇인지 설명 어려움.
```

### scCEDI-K v2 서비스 (설계안)

```
┌───────────────────────────────────────────────────┐
│  2026년 4월 4일 서울 기상가뭄 현황                  │
│                                                   │
│  ◆ 기상가뭄 등급: [후향검증 후 확정]                │
│     scCEDI-K = -1.23                              │
│                                                   │
│  ◆ 가뭄 지속기간: 48일째                           │
│  ◆ 최근 90일 강수: 평년의 52%                       │
│  ◆ 정상 회복에 필요한 강수: 약 55mm/일              │
│     (유출보정 반영된 실제 필요량)                     │
│  ◆ 전주 대비: 악화 (↓0.15)                         │
└───────────────────────────────────────────────────┘
→ 지수값 + 지속일수 + 평년비 + 실제 필요 강수량
→ 국민이 "비가 얼마나 부족하고, 얼마나 오래됐고, 얼마나 와야 하는지" 파악 가능
```

## 6. 한 줄 요약

> **scCEDI-K v2는 원본 EDI의 핵심 DNA(시간가중 EP + 자동확장 DS + 일강수 전용)를 100% 보존하면서, 딱 3가지(유출보정 · rolling 기후학 · 비모수 표준화)만 추가하여 한국형 운영 약점을 해결한 알고리즘이다.**
