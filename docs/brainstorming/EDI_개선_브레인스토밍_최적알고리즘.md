# EDI 개선 브레인스토밍 및 최적 알고리즘 도출

> **목적**: 1999년 Byun & Wilhite 원본 EDI의 한계점을 체계적으로 식별하고, SPI처럼 복수 기간을 나열하는 방식이 아닌 **"하나의 가뭄지수로 기상가뭄을 대표"**할 수 있는 최적 개선안을 도출한다.
> 
> **핵심 전제**: 돌발가뭄은 제외한다. 기상가뭄(강수 기반)에 집중한다.

---

## 1. 원본 EDI(1999)의 강점 재확인

원본 EDI가 SPI 대비 우위를 가지는 근본적 이유를 먼저 고정해야 개선 방향이 흔들리지 않는다.

| 강점 | 설명 |
|:-----|:-----|
| **일단위 계산** | 월경계 효과 없이 해갈 시점을 정밀 포착 |
| **시간가중 유효강수(EP)** | 최근 비에 큰 가중치, 오래된 비에 작은 가중치 → 현재 물가용량 추정 |
| **자동 확장 DS** | 가뭄이 길어지면 평가창이 자동으로 확장 → 단기/장기 통합 |
| **연쇄 지표 체계** | EP → DEP → SEP → PRN → EDI로 각 단계가 설명 가능 |
| **강수 전용** | 입력이 일강수량만 → 관측 밀도 높고 장기 자료 확보 용이 |

> **결론**: 위 다섯 가지는 개선 과정에서 반드시 보존해야 한다.

## 2. 원본 EDI의 한계점 분석 (6가지 축)

### 2.1. EP 가중함수의 이론적 임의성

- 식 (1), (2), (3) 중 어떤 것이 최선인지 원 논문도 확정하지 못했다.
- 식 (2)의 조화급수( $\sum 1/n$ ) 가중치는 물리적 기반이 명확하지 않다.
- **실무 문제**: 지역 유역 특성(토양, 경사, 식생)에 따라 물의 잔류 특성이 다른데, 고정 가중함수로는 이를 반영 불가.

### 2.2. 집중호우 후 급격한 유출 미반영

- Kim et al.(2009)이 지적한 핵심 한계.
- 한반도처럼 여름 집중호우 → 급경사 유출이 빠른 환경에서, 원본 EDI는 큰 비가 오면 유효수자원이 크게 늘어난 것으로 과대평가.
- 2006년 서울 사례: 7월 집중호우 후 8~12월 물부족이 있었으나 EDI는 "습윤" 판정.

### 2.3. 표준화 방식의 한계

- EDI = DEP / ST(DEP)에서 ST는 **해당 달력일의 장기 표준편차**.
- 한반도 강수는 계절성이 극심하여 (건기 표준편차 ≪ 우기 표준편차), 같은 EDI 값이라도 **체감과 실제 영향이 계절에 따라 크게 다르다**.
- 감마분포 피팅 문제: 30년 일자료로 달력일별 분포를 추정하면 샘플이 30개에 불과 → 분포 추정 불안정.

### 2.4. 기후 비정상성 미고려

- 원본 EDI는 장기 기후평균(MEP)과 표준편차(ST)를 **고정된 기후값**으로 사용.
- 기후변화로 강수 패턴이 변하면(특히 집중호우 빈도 증가, 건기 장기화) 과거 기후학이 현재를 대표하지 못함.
- 30년 평년값의 갱신 주기(10년)도 비정상성에 비해 느림.

### 2.5. 절대 물부족량의 부재

- EDI는 상대적 표준화 지수이므로, **봄(원래 물이 적은 계절)에 EDI=-1.0이면 실제로는 매우 심각하지만, 여름에 EDI=-1.0이면 덜 심각**할 수 있다.
- 대국민 서비스에서 "지금 실제로 물이 얼마나 부족한가"를 보여주기 어려움.
- Kim et al.(2009)이 AWRI를 제안한 배경.

### 2.6. 단일 기간(DS=365) 더미값의 임의성

- 장기 기준 365일은 기후주기상 설득력이 있으나, 단기 기준 15일은 **이론적 근거보다는 실무 가정**.
- 한반도 건기와 우기의 길이가 비대칭적(건기가 훨씬 길음)이므로, 고정 더미 DS가 최적인지 재검토 필요.

## 3. 브레인스토밍: 6가지 개선 아이디어

### 아이디어 A: 적응형 커널 가중함수 (Adaptive Kernel EP)

**문제**: 고정 조화급수 가중치는 모든 지역·계절에 동일하게 적용됨.

**해결**:
- EP 가중함수를 **지수감쇠 커널**로 통일하되, 감쇠율(τ)을 **지역·계절별로 적응**시킨다.
- 수식: `EP(t) = Σ P(t-m) × exp(-m/τ)`
- τ는 유역의 물 잔류 특성을 반영하는 파라미터로, **자기상관함수(ACF)** 또는 **유출 응답함수**에서 추정 가능.
- 계절별 τ를 다르게 설정: 우기에는 τ↓(빠른 유출), 건기에는 τ↑(느린 소모).

**장점**: 물리적 기반 강화, 지역 맞춤형 운영 가능.
**리스크**: τ 추정을 위한 추가 데이터/보정 필요.

---

### 아이디어 B: 집중호우 유출보정 (CEDI 확장)

**문제**: 일정 임계값 이상의 호우는 빠르게 유출되어 유효수자원 기여가 급감함.

**해결** (Kim 2009의 CEDI를 확장):
1. 임계값 이상(Pthreshold) 강수의 초과분에 대해 **급속감쇠 함수** 적용.
2. `CEP(t) = EP_normal(t) + EP_excess(t) × exp(-m/τ_fast)`
3. τ_fast ≈ 3~5일 (τ_normal의 1/10~1/20 수준)
4. Pthreshold는 지역별 상위 5~10% 일강수량으로 **자동 설정** (고정 80mm 대신).

**개선점 vs Kim(2009)**:
- 고정 80mm → **지역별 분위수 기반 동적 임계값**으로 일반화.
- 서울만이 아닌 전국 160여 지점에 적용 가능.

---

### 아이디어 C: 비매개변수 표준화 (Empirical Quantile Mapping)

**문제**: 감마분포 피팅은 샘플 부족(달력일당 30개)으로 불안정하고, 한반도 강수 분포가 감마에 잘 맞지 않는 계절이 있음.

**해결**:
1. DEP를 감마분포로 변환하는 대신, **경험적 백분위(empirical quantile)** 방식으로 표준화.
2. 구체적으로: 달력일 ±15일 이동창(window)의 과거 DEP 값을 풀링(pooling)하여 경험적 CDF를 구성.
   - 30년 × 31일창 = ~930개 샘플 → 분포 추정 안정성 크게 향상.
3. 경험적 CDF에서 확률값을 구한 뒤, **정규분포 역함수**로 변환하여 표준화.
   - 즉, `E-EDI = Φ⁻¹(F_emp(DEP))`

**장점**:
- 감마 가정 불필요 → 분포 적합 오류 제거.
- 모든 기후대·계절에 자동 적응.
- ±15일 풀링으로 샘플 수 대폭 증가.

**주의**: 극단값(꼬리) 추정은 경험적 방법이 약할 수 있음 → **일반화파레토분포(GPD)**로 꼬리 외삽 보완 가능.

---

### 아이디어 D: 이동 기후학 (Moving Climatology for Non-stationarity)

**문제**: 고정 30년 평년값은 기후변화 추세를 반영하지 못함.

**해결**:
1. MEP와 ST 계산에 **가중 이동 기후학** 적용.
2. 예: 최근 30년에 대해 **지수적 가중 이동평균**으로 MEP 산정.
   - `MEP_moving(t) = Σ w(y) × EP_calendar_day(y)` where `w(y) = exp(-(current_year - y)/10)`
   - 최근 연도에 더 큰 가중치 → 기후변화 추세 반영.
3. 또는 **60년 자료를 사용하되 최근 30년에 2배 가중치**를 주는 하이브리드 방식.

**장점**: 기후변화 하에서도 "현재 기후에 대한 상대적 부족"을 더 정확하게 산정.
**주의**: 가중치 선택의 임의성 → 민감도 분석 필수.

---

### 아이디어 E: 절대 물부족 보조지수 내장 (AWRI 통합)

**문제**: EDI는 상대지수이므로 계절별 절대 물부족을 보여주지 못함.

**해결**:
1. E-EDI 산출 과정에서 **보정 유효강수량(CEP) 자체**를 정규화하여 AWRI를 자동 산출.
2. `AWRI(t) = CEP(t) / max(CEP_climatology)` → 0~1 스케일.
3. 대국민 서비스에서 E-EDI(상대등급)과 AWRI(절대수준)를 항상 쌍으로 제공.

**효과**: "현재 평균보다 얼마나 부족한가(E-EDI)" + "현재 실제 물이 얼마나 적은가(AWRI)"를 하나의 체계에서 동시 제공.

---

### 아이디어 F: 다중지수 합의도 점수 내장 (Consensus Score)

**문제**: 단일 지수만으로는 진단의 신뢰도를 담보하기 어려움. 회의에서도 SPI 3/6 간 불일치 문제가 반복됨.

**해결**:
1. E-EDI를 대표지수로 산출한 뒤, **E-EDI 산출 과정의 부산물**로 다중 시간척도 신호를 추출.
   - 단기 신호: DS=30일 기준 DEP 부호
   - 중기 신호: DS=90일 기준 DEP 부호
   - 장기 신호: DS=365일 기준 DEP 부호
   - 강수 백분위 부호
2. 합의도 점수 = (가뭄 방향을 보이는 척도의 수) / (전체 척도 수)
   - 예: 4개 중 4개 모두 음수 → 합의도 "매우 높음"
   - 3개 → "높음", 2개 → "보통", 1개 → "낮음"
3. 합의도를 E-EDI와 함께 제공하되, **E-EDI 등급 판정 자체에는 합의도를 혼합하지 않음** (계층 분리 원칙 유지).

**효과**: SPI 1/3/6을 별도로 나열하지 않아도, E-EDI 하나의 체계 안에서 "다른 시간척도도 같은 방향인가"를 자동으로 보여줄 수 있음.

## 4. 최적 알고리즘 종합: Enhanced EDI (E-EDI)

위 6가지 아이디어를 통합한 **E-EDI** 알고리즘을 제안한다.

### 4.1. 설계 원칙 및 적용 우선순위

6개 설계 원칙을 **P0 → P1 → P2** 3단계 우선순위로 구분한다.

- **P0 (필수 선행)**: 이것이 없으면 E-EDI 자체가 성립하지 않는 기반 원칙. Phase 1에서 반드시 확보.
- **P1 (핵심 개선)**: 원본 EDI 대비 실질적 성능 향상을 만드는 핵심 원칙. Phase 1~2에서 구현·검증.
- **P2 (부가가치)**: 서비스 품질과 설명력을 높이는 원칙. P0·P1이 안정된 뒤 Phase 2~3에서 추가.

| 우선순위 | # | 설계 원칙 | 근거 | 관련 STEP | 선행 의존 |
|:--------:|:-:|:---------|:-----|:---------:|:--------:|
| **P0** | ① | **입력은 일강수량만** | 원본 EDI의 본질. 추가 입력을 요구하면 관측 밀도·장기성·운영 단순성이 모두 훼손됨. 기상가뭄의 정의(강수 부족)와도 직결. | 전체 | 없음 |
| **P0** | ② | **단일 지수로 기상가뭄 대표** | SPI 복수 기간 나열의 혼선(회의록 핵심 문제)을 해결하는 프로젝트 존재 이유. 이 원칙이 빠지면 개선의 의미 자체가 사라짐. | STEP 4, 6 | ① |
| **P1** | ③ | **비매개변수 표준화** | 감마분포 피팅 불안정(샘플 30개)은 현행 SPI·EDI 운영의 가장 실질적 약점. 경험적 CDF + 풀링으로 즉시 해결 가능하며, 구현 난이도 대비 효과가 가장 큼. | STEP 4 | ①② |
| **P1** | ④ | **지역·계절 적응형** | 한반도 강수의 극단적 계절성(우기 집중, 건기 장기화)을 반영하지 않으면 유출보정·EP 감쇠 모두 왜곡됨. 적응형 τ와 동적 Pthreshold가 여기에 해당. | STEP 1, 2 | ①② |
| **P2** | ⑤ | **보조정보는 부산물로 자동 생성** | AWRI·합의도·PRN은 대국민 설명력을 결정적으로 높이지만, E-EDI 지수 자체의 정확도와는 독립적. P0·P1이 확정된 뒤 서비스 레이어에서 추가해도 무방. | STEP 5 | ①②③④ |
| **P2** | ⑥ | **기후 비정상성 대응** | 이동 기후학은 장기적으로 반드시 필요하지만, 현 시점에서는 고정 30년 평년값으로도 운영 가능. 반감기·가중치 선택의 민감도 분석이 선행되어야 하므로 Phase 2~3에서 도입. | STEP 3 | ①②③④ |

#### 적용 순서 요약

```
Phase 1 (즉시)
  P0-① 일강수량 전용 체계 확립
  P0-② 단일 대표지수 산출 파이프라인 구축
  P1-③ 비매개변수 표준화 모듈 (경험적 CDF + 풀링)
  P1-④ 적응형 EP 커널 + 유출보정 (계절별 τ, 동적 Pthreshold)
       ↓ 과거 사례 검증 통과 후
Phase 2 (검증 후)
  P2-⑤ AWRI, 합의도, PRN 보조지표 모듈
  P2-⑥ 이동 기후학 (민감도 분석 → 반감기 확정)
       ↓ 시범 운영 후
Phase 3 (서비스 전환)
  전체 통합 및 공식 운영
```

> **핵심 판단 근거**: P1-③(비매개변수 표준화)를 P1-④(적응형 커널)보다 먼저 둔 이유는, 표준화 방식의 변경이 **기존 코드에 미치는 영향이 국소적**(STEP 4만 수정)이고 **검증이 빠른** 반면, 적응형 커널은 STEP 1~2 전체를 변경하여 **전파 영향이 크기** 때문이다. 즉, 리스크가 작은 개선부터 확정하고, 전파 범위가 넓은 개선은 그 위에 얹는 전략이다.

### 4.2. 전체 알고리즘 흐름

```
┌─────────────────────────────────────────────────────┐
│                    입력: 일강수량 P[t]               │
│               (장기 시계열, 최소 30년 이상)           │
└─────────────┬───────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────────────────────┐
│  STEP 1: 유출보정 강수량(Corrected Precipitation)     │
│                                                     │
│  Pthreshold = 해당 지점의 일강수 상위 5% 값            │
│  P_eff[t] = min(P[t], Pthreshold)                   │
│           + max(0, P[t]-Pthreshold) × Runoff_Factor │
│  Runoff_Factor = exp(-m/τ_fast), τ_fast ~ 3일       │
└─────────────┬───────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────────────────────┐
│  STEP 2: 적응형 유효강수량(Adaptive EP)               │
│                                                     │
│  CEP[t] = Σ(m=1→DS) P_eff[t-m] × exp(-m/τ)        │
│                                                     │
│  τ = 지역·계절별 물 잔류 파라미터                      │
│    - 기본값: τ = 150일 (원본 식(2)와 유사한 감쇠)      │
│    - 우기(6~9월): τ × 0.7 (빠른 유출 환경)            │
│    - 건기(10~5월): τ × 1.2 (느린 소모 환경)           │
│                                                     │
│  DS 결정 (원본 원리 유지):                            │
│    dummy_DS = 365                                   │
│    DS[t] = dummy_DS + dry_duration[t] - 1           │
└─────────────┬───────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────────────────────┐
│  STEP 3: 이동 기후학 기반 편차 계산                    │
│                                                     │
│  MCEP[t] = 해당 달력일의 가중 이동평균 CEP             │
│    - 최근 30년에 지수가중, 반감기 10년                  │
│    - ±7일 이동평균으로 평활화                          │
│                                                     │
│  DCEP[t] = CEP[t] - MCEP[t]                         │
│  (현재 보정유효강수 - 기후학 보정유효강수)               │
└─────────────┬───────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────────────────────┐
│  STEP 4: 비매개변수 표준화 (E-EDI 산출)                │
│                                                     │
│  해당 달력일 ±15일 창의 과거 DCEP 값을 풀링            │
│  → 경험적 CDF F_emp 구성 (30년×31일 ≈ 930개 샘플)     │
│                                                     │
│  E-EDI[t] = Φ⁻¹(F_emp(DCEP[t]))                    │
│                                                     │
│  (극단값 보완: 양 꼬리에 GPD 외삽 적용 가능)            │
└─────────────┬───────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────────────────────┐
│  STEP 5: 보조지표 자동 산출 (부산물)                   │
│                                                     │
│  ① AWRI[t] = CEP[t] / CEP_climate_max              │
│     → 0~1 스케일, 절대 물부족 수준                     │
│                                                     │
│  ② PRN[t] = DCEP[t] / Σ(1/n, n=1→DS)              │
│     → 정상 회복에 필요한 1일 강수량                     │
│                                                     │
│  ③ 합의도 점수:                                      │
│     - DCEP_30[t] 부호 (단기)                         │
│     - DCEP_90[t] 부호 (중기)                         │
│     - DCEP_365[t] 부호 (장기)                        │
│     - 강수 백분위 부호                                │
│     → 음의 부호 비율로 합의도 산정                     │
│                                                     │
│  ④ 지속일수 = E-EDI < 0 연속 일수                     │
│  ⑤ 가뭄 사건 누적(AEDI) = 연속 음의 E-EDI 합           │
└─────────────┬───────────────────────────────────────┘
              │
              ▼
┌─────────────────────────────────────────────────────┐
│  STEP 6: 등급 판정                                   │
│                                                     │
│  E-EDI 값     등급        색상                       │
│  ─────────────────────────────────                  │
│   ≥ 0.0       정상        녹색                       │
│  -0.5 ~ 0.0   관심        연노랑                     │
│  -1.0 ~ -0.5  약한 가뭄    노랑                      │
│  -1.5 ~ -1.0  보통 가뭄    주황                      │
│  -2.0 ~ -1.5  심한 가뭄    빨강                      │
│  < -2.0       극심 가뭄    보라                       │
│                                                     │
│  + 합의도 표시: ●●●● (매우높음), ●●●○ (높음) 등       │
└─────────────────────────────────────────────────────┘
```

### 4.3. 의사코드 (Pseudocode)

```python
# ============================================================
# Enhanced EDI (E-EDI) 알고리즘 의사코드
# ============================================================

def compute_E_EDI(daily_precip, station_meta):
    """
    Parameters
    ----------
    daily_precip : array, shape (N_days,)
        장기 일강수량 시계열 (최소 30년)
    station_meta : dict
        지점 메타정보 (위도, 경도, 고도, 유역 특성 등)
    
    Returns
    -------
    E_EDI : array, 표준화된 가뭄지수 시계열
    AWRI  : array, 절대 물부족 지수 시계열
    PRN   : array, 정상회복 필요 강수량 시계열
    consensus : array, 합의도 점수 시계열
    """
    
    N = len(daily_precip)
    
    # ----------------------------------------------------------
    # STEP 1: 유출보정 강수량
    # ----------------------------------------------------------
    P_threshold = np.percentile(daily_precip[daily_precip > 0], 95)
    tau_fast = 3  # 급속유출 반감기 (일)
    
    P_eff = np.copy(daily_precip)
    for t in range(N):
        if daily_precip[t] > P_threshold:
            excess = daily_precip[t] - P_threshold
            P_eff[t] = P_threshold  # 임계 이하는 그대로
            # 초과분은 향후 며칠에 걸쳐 감쇠 분배
            for m in range(1, 30):  # 최대 30일까지 감쇠 효과
                if t + m < N:
                    P_eff[t + m] += excess * np.exp(-m / tau_fast) * (1 - np.exp(-1/tau_fast))
    
    # ----------------------------------------------------------
    # STEP 2: 적응형 유효강수량 (Adaptive CEP)
    # ----------------------------------------------------------
    tau_base = 150  # 기본 감쇠 파라미터
    dummy_DS = 365
    
    CEP = np.zeros(N)
    dry_duration = np.zeros(N, dtype=int)
    
    for t in range(dummy_DS, N):
        # 계절별 τ 조정
        month = get_month(t)
        if 6 <= month <= 9:  # 우기
            tau = tau_base * 0.7
        else:  # 건기
            tau = tau_base * 1.2
        
        # DS 결정 (가뭄이 길어지면 자동 확장)
        DS = dummy_DS + max(0, dry_duration[t-1] - 1)
        DS = min(DS, t)  # 자료 범위 내로 제한
        
        # 적응형 EP 계산
        for m in range(1, DS + 1):
            weight = np.exp(-m / tau)
            CEP[t] += P_eff[t - m] * weight
    
    # ----------------------------------------------------------
    # STEP 3: 이동 기후학 기반 편차
    # ----------------------------------------------------------
    # 달력일별 가중 이동평균 CEP (반감기 10년)
    MCEP = compute_moving_climatology(CEP, halflife_years=10, window_days=7)
    
    DCEP = CEP - MCEP  # 편차
    
    # dry duration 갱신 (DCEP 기반)
    for t in range(1, N):
        if DCEP[t] < 0:
            dry_duration[t] = dry_duration[t-1] + 1
        else:
            dry_duration[t] = 0
    
    # ----------------------------------------------------------
    # STEP 4: 비매개변수 표준화
    # ----------------------------------------------------------
    E_EDI = np.zeros(N)
    
    for t in range(N):
        doy = get_day_of_year(t)
        
        # ±15일 풀링 (달력일 기준)
        pool = get_historical_DCEP_pool(DCEP, doy, window=15)
        
        # 경험적 CDF
        ecdf_value = empirical_cdf(DCEP[t], pool)
        
        # 극단값 처리 (0 또는 1에 너무 가까우면 GPD 외삽)
        ecdf_value = np.clip(ecdf_value, 0.001, 0.999)
        
        # 정규분포 역변환
        E_EDI[t] = norm.ppf(ecdf_value)
    
    # ----------------------------------------------------------
    # STEP 5: 보조지표 자동 산출
    # ----------------------------------------------------------
    
    # ① AWRI (절대 물부족 지수)
    CEP_max = compute_calendar_day_max(CEP)
    AWRI = CEP / CEP_max
    
    # ② PRN (정상회복 필요 강수량)
    PRN = np.zeros(N)
    for t in range(N):
        DS = dummy_DS + max(0, dry_duration[t] - 1)
        harmonic_sum = sum(1/n for n in range(1, DS + 1))
        if DCEP[t] < 0:
            PRN[t] = -DCEP[t] / harmonic_sum
        else:
            PRN[t] = 0
    
    # ③ 합의도 점수
    consensus = np.zeros(N)
    for t in range(N):
        signals = []
        for ds in [30, 90, 365]:
            dcep_ds = compute_DCEP_at_scale(P_eff, t, ds, MCEP)
            signals.append(1 if dcep_ds < 0 else 0)
        # 강수 백분위 부호
        pct = precipitation_percentile(daily_precip, t, window=90)
        signals.append(1 if pct < 50 else 0)
        
        consensus[t] = sum(signals) / len(signals)
    
    return E_EDI, AWRI, PRN, consensus
```

## 5. 원본 EDI vs E-EDI 비교

| 비교 항목 | 원본 EDI (1999) | E-EDI (개선안) |
|:---------|:---------------|:--------------|
| **EP 가중함수** | 조화급수(고정) | 지수감쇠(적응형, 계절·지역별 τ) |
| **집중호우 처리** | 전량 유효 반영 | 유출보정 (지점별 동적 임계값) |
| **기후학** | 고정 30년 평균 | 이동 가중 기후학 (반감기 10년) |
| **표준화** | DEP/ST(DEP) (모수적) | 경험적 CDF → 정규분포 역변환 (비모수적) |
| **DS 기본값** | 365 + 15 (고정) | 365 (적응형, 건기/우기 τ로 간접 반영) |
| **절대 물부족** | 별도 없음 | AWRI 자동 산출 |
| **합의도** | 별도 없음 | 다중 시간척도 합의도 점수 자동 산출 |
| **사건 비교** | 별도 없음 | AEDI, YAEDI 연계 가능 |
| **입력자료** | 일강수량만 | 일강수량만 (동일) |
| **계산 단위** | 일별 | 일별 (동일) |

### 6.1. 재현성 검증 (Historical Validation)

| 검증 대상 | 방법 |
|:---------|:-----|
| 1899~1903 서울 메가가뭄 | E-EDI가 원본 EDI만큼 또는 더 잘 장기 누적을 표현하는가 |
| 1965년 봄 단기 가뭄 | E-EDI가 단기 가뭄을 놓치지 않는가 |
| 2006년 집중호우 후 가을 건조 | 유출보정으로 가을 가뭄을 더 잘 잡는가 |
| 2015년 전국 가뭄 | 지역별 E-EDI 분포가 실제 피해와 부합하는가 |
| 2022~2023년 가뭄 | 최근 사례로 운영 가능성 확인 |

### 6.2. SPI/원본 EDI 대비 성능 비교

- 상관분석: E-EDI vs 저수율, 하천유량 (참고 영향정보)
- 히트레이트: 과거 가뭄 선언/해갈 시점과의 일치율
- 안정성: 하루 강수 변화에 따른 등급 변동 빈도 (불필요한 flip-flop 최소화)

### 6.3. 민감도 분석

- τ 변화에 따른 E-EDI 반응
- Pthreshold 변화에 따른 유출보정 효과
- 풀링 창 크기(±15일 vs ±30일) 변화에 따른 표준화 안정성
- 이동 기후학 반감기(5년 vs 10년 vs 15년) 변화에 따른 비정상성 대응 효과

## 8. 결론

1999년 Byun & Wilhite의 EDI는 "하나의 지수로 장·단기 기상가뭄을 모두 추적한다"는 **근본 설계가 이미 뛰어나다**. 따라서 최적의 개선 방향은 EDI의 구조를 버리고 새로운 체계를 만드는 것이 아니라, **EDI의 뼈대(EP → DEP → 표준화 → DS 자동확장)를 보존하면서 아래 6가지를 덧씌우는 것**이다.

| 개선 축 | 핵심 내용 |
|:--------|:---------|
| ① 적응형 가중함수 | 고정 조화급수 → 지역·계절별 지수감쇠 커널 |
| ② 유출보정 | 집중호우 초과분에 급속감쇠 적용 (Kim 2009 CEDI 확장) |
| ③ 비매개변수 표준화 | 감마분포 → 경험적 CDF + 정규분포 역변환 |
| ④ 이동 기후학 | 고정 30년 → 가중 이동평균 기후학 |
| ⑤ 절대 물부족 내장 | AWRI를 체계 내 부산물로 자동 산출 |
| ⑥ 합의도 내장 | 다중 시간척도 부호 일치도를 부산물로 자동 산출 |

이를 통해 **SPI 방식(복수 기간 나열)에 의존하지 않으면서**, **하나의 대표지수(E-EDI)와 그 부산물(AWRI, PRN, 합의도)만으로 기상가뭄 서비스를 완결적으로 구성**할 수 있다.
