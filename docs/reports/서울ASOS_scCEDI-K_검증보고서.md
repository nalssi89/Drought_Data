# 서울 ASOS 기반 scCEDI-K 검증보고서

## 1. 목적

본 보고서는 **서울 ASOS 108 일강수량 자료만** 사용하여 원본 EDI와 scCEDI-K를 비교하고, 서울의 대표적 가뭄 사례에서 scCEDI-K가 실제 가뭄 상황을 더 잘 설명하는지 검토하기 위해 작성하였다.

이번 검증의 목적은 두 가지다.

1. 강릉 사례에서 확인된 scCEDI-K의 장점이 서울에서도 유지되는지 확인한다.
2. 서울 사례를 바탕으로 scCEDI-K가 **공식 기상가뭄 서비스의 병행/증강 지수 후보**가 될 수 있는지 평가한다.

---

## 2. 분석 범위와 자료

### 2.1 관측소

- **서울 ASOS 108**

### 2.2 사용 자료

- `pipeline/data/raw/asos_precip_108_1970_1989.csv`
- `pipeline/data/raw/asos_precip_108_1990_2025.csv`
- `pipeline/data/processed/edi_long_108_1990_2025.csv`
- `pipeline/data/processed/sccedik_long_108_1990_2025.csv`
- `pipeline/data/processed/seoul_108_case_compare_with_daily_precip.png`

### 2.3 산출 방식

- 원본 EDI: 1991–2020 고정 기후평년 기준
- scCEDI-K: rolling 30년 기후학 + 비모수 표준화 + 유출보정(alpha=0.2)

### 2.4 분석 사례

서울에서 ASOS 기반으로 의미 있게 비교 가능한 현대 사례를 우선 선택했다.

1. **2006년 7~12월**
   - 7월 큰 강수가 있었지만 가을에 다시 건조해진 사례
   - 원형 EDI의 한계를 보여주는 대표 사례로 기존 문헌 및 저장소 메모에서 반복 언급됨

2. **2014년 하반기 ~ 2015년 11월**
   - 서울·수도권 현대 가뭄 대표 사례
   - 외부 근거상 2015년 서울·경기 강수량 부족이 뚜렷하게 보고됨

## 3. 결과 요약

## 3.1. 2006년 사례: 7월 집중호우 후 가을 재건조

### 기간
- `2006-07-01 ~ 2006-12-31`

### 수치 요약

- 원본 EDI 평균/최소/최대: `0.605 / -0.327 / 2.916`
- scCEDI-K 평균/최소/최대: `0.380 / -0.363 / 2.183`

### 월평균 비교

| 월 | 원본 EDI | scCEDI-K |
|---|---:|---:|
| 2006-07 | 1.369 | 1.134 |
| 2006-08 | 1.143 | 1.096 |
| 2006-09 | 0.403 | 0.206 |
| 2006-10 | 0.171 | **-0.185** |
| 2006-11 | 0.274 | **-0.002** |
| 2006-12 | 0.252 | 0.015 |

### 해석

원본 EDI는 7월 집중호우 이후 하반기 대부분을 계속 정상~습윤 쪽으로 평가한다. 반면 scCEDI-K는 9월 이후 빠르게 약화되고, **10월부터 음수 재진입**을 보인다.

즉, 이 사례에서는 scCEDI-K가 **“여름 큰 비가 있었어도 가을에 다시 건조해질 수 있다”** 는 실제 서울 상황을 원본 EDI보다 더 잘 반영한다.

다만 건조 강도 자체가 매우 강한 수준으로 내려가지는 않으므로, 2006 사례는 **강한 차이의 사례라기보다 방향성 개선 사례**로 보는 것이 적절하다.

---

## 3.2. 2014H2–2015 사례: 현대 서울 장기가뭄

### 기간
- `2014-07-01 ~ 2015-11-30`

### 수치 요약

- 원본 EDI 평균/최소/최대: `-1.225 / -1.663 / -0.239`
- scCEDI-K 평균/최소/최대: `-1.934 / -3.270 / -0.326`

### 임계값 이하 일수 비교

| 기준 | 원본 EDI | scCEDI-K |
|---|---:|---:|
| `<= -1.0` | 427일 | **500일** |
| `<= -1.5` | 40일 | **405일** |
| `<= -2.0` | 0일 | **140일** |

### 주요 월평균 비교

| 월 | 원본 EDI | scCEDI-K |
|---|---:|---:|
| 2014-07 | -1.106 | **-1.832** |
| 2014-11 | -1.370 | **-1.827** |
| 2015-03 | -1.461 | **-2.897** |
| 2015-06 | -1.121 | **-1.531** |
| 2015-09 | -1.438 | **-3.270** |
| 2015-10 | -1.469 | **-2.846** |
| 2015-11 | -1.222 | **-1.586** |

### 해석

두 지수 모두 장기 가뭄을 잡아내지만, **scCEDI-K는 가뭄의 지속성과 심화를 훨씬 더 강하게 표현**한다.

특히 다음이 중요하다.

1. **장기 지속성 유지**
   - 원본 EDI도 지속적 음수를 보이지만, scCEDI-K는 더 긴 기간 동안 더 낮은 수준을 유지한다.

2. **심화 강도 차이**
   - 원본 EDI는 `-2.0` 이하 극심 단계에 한 번도 들어가지 않지만,
   - scCEDI-K는 `-2.0` 이하가 140일로 나타난다.

3. **서비스 설명력 강화**
   - 대국민/행정 서비스에서는 “가뭄이 계속 심해지고 있다”는 신호가 중요하다.
   - 이 점에서 scCEDI-K는 원본 EDI보다 더 선명한 경고 신호를 제공한다.

즉, 2014H2–2015 사례는 서울에서도 scCEDI-K가 **장기 누적 부족을 더 강하고 지속적으로 표현**할 수 있음을 보여준다.

## 5. 서울 적용 가능성 평가

## 5.1. 긍정 근거

서울 ASOS 자료 기반 분석에서 scCEDI-K의 강점은 다음과 같이 확인된다.

1. **강릉 사례만의 현상이 아니다.**
   - 서울 2006, 2014H2–2015에서도 원본 EDI와 다른 반응을 보이며, 서울에서도 일관된 차별성이 나타난다.

2. **집중호우 후 재건조를 더 잘 반영한다.**
   - 2006 사례에서 원본 EDI는 계속 양수 쪽에 머무는 반면, scCEDI-K는 가을 재건조를 일부 포착한다.

3. **장기 가뭄 지속성과 심화를 더 강하게 표현한다.**
   - 2014H2–2015 사례에서 scCEDI-K는 장기 누적 부족을 더 선명하게 유지한다.

4. **서비스 경고 신호가 더 분명하다.**
   - 원본 EDI보다 가뭄 심화 구간을 더 깊고 오래 보여주어, 대국민/행정 설명력이 높다.

## 5.2. 보수적으로 봐야 할 점

다만 다음 점은 함께 고려해야 한다.

1. **서울 1개 지점은 서울권 전체를 완전히 대표하지 않는다.**
   - 본 검증은 어디까지나 **서울 ASOS 108 지점 기반 점검정(point validation)** 이다.

2. **서울 사례만으로 전국 대체를 결론내릴 수는 없다.**
   - 강릉과 서울은 기후체계가 다르므로 의미 있는 확장 검증이지만,
   - 전국 서비스 대체 주장을 하려면 다른 권역도 추가 검증이 필요하다.

3. **2006 사례는 강한 우위라기보다 방향성 개선이다.**
   - 완전한 극적 개선이라기보다, 원본 EDI의 낙관 편향을 줄이는 효과가 보인다.

---

## 6. 최종 판단

서울 ASOS 108 자료 기반 검증 결과는 다음과 같이 정리할 수 있다.

1. **scCEDI-K는 서울에서도 원본 EDI보다 더 현실적인 가뭄 설명력을 보인다.**
2. **특히 장기 누적 부족과 집중호우 후 재건조 문제에서 개선 방향이 확인된다.**
3. 따라서 **강릉 사례에 이어 서울 사례까지 확보했다는 점에서, scCEDI-K는 단일 대표 기상가뭄 서비스의 병행/증강 후보로 검토할 충분한 근거를 가진다.**

다만 현재 단계에서 가장 적절한 결론은 다음과 같다.

> **서울 ASOS 기반 검증은 scCEDI-K의 일반화 가능성을 지지하지만, 이는 우선 “공식 서비스 병행/증강” 근거로 해석하는 것이 적절하며, 즉시 SPI를 완전 대체하는 최종 근거로 쓰기에는 추가 권역 검증이 더 필요하다.**
